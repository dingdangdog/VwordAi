# 如题

## 工作流程

1. 用户输入小说名称、作者等信息；
2. AI基于用户输入信息获取到小说全文并保存；
3. AI将小说全文分章节
4. AI分析小说全文，找出主角配角，并将重要角色整理存储；
5. AI分析角色性别、性格，选取合适的TTS角色与小说角色绑定（当然还需要几个龙套男女角色tts，用于一些路人等）；
6. AI将一个章节内容按照小说角色拆分解析为对话稿（角本）；备注：这一步可能会发现前面步骤没有分析到的小说角色，可以重复4-5两步，进行角色数据增加；
7. AI将对话稿转为TTS需要的参数数据格式（json/SSML等）；
8. AI拿着参数调用TTS，生成各种对话片段；
9. AI使用ffmpeg指令合并对话片段为一个完整音频；
